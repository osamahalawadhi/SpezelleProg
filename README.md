# SpezielleProg-DevOps

Dieses Repository dient als praktisches Beispiel für die Anwendung von DevOps-Praktiken im Kontext spezieller Programmierung. Es umfasst mehrere Aufgaben, die verschiedene Aspekte von DevOps, wie Automatisierung, Continuous Integration und Continuous Deployment, abdecken.

## Inhalte des Repositories

* `aufgabe1/` – Lösungen und Skripte für Aufgabe 1
* `aufgabe2/` – Lösungen und Skripte für Aufgabe 2
* `aufgabe3/` – Lösungen und Skripte für Aufgabe 3
* `aufgabe4/` – Lösungen und Skripte für Aufgabe 4
* `aufgabe6/` – Lösungen und Skripte für Aufgabe 6
* `aufgabe7/` – Lösungen und Skripte für Aufgabe 7
* `console_rag_bot/` – Implementierung eines Konsolen-basierten RAG-Bots
* `README.md` – Dieses Dokument

## Voraussetzungen

Um mit diesem Projekt zu arbeiten, stelle sicher, dass folgende Software auf deinem System installiert ist:

* [Python 3.x](https://www.python.org/downloads/)
* [Docker](https://www.docker.com/get-started)
* [Git](https://git-scm.com/)

Für bestimmte Aufgaben können zusätzliche Tools erforderlich sein. Sie sind in den jeweiligen Unterverzeichnissen dokumentiert.

## Installation und Nutzung

1. **Repository klonen:**

```bash
git clone https://github.com/osamahalawadhi/SpezielleProg-DevOps-
cd SpezielleProg-DevOps-
```

2. **Abhängigkeiten installieren:**

```bash
pip install -r requirements.txt
```

3. **Docker-Container starten (falls erforderlich):**

```bash
docker-compose up
```

4. **Aufgaben ausführen:**

Wechsle in das entsprechende Verzeichnis und folge den dortigen Anweisungen.
